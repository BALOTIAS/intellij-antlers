# Security Policy

## Supported Versions

`intellij-antlers` is distributed as a single, continuously released IntelliJ
Platform plugin. Security fixes are shipped in a new release rather than
backported, so only the latest published version is supported.

| Version          | Supported          |
| ---------------- | ------------------ |
| Latest release   | :white_check_mark: |
| Older releases   | :x:                |

If you are running an older build, please update to the
[latest release](https://github.com/BALOTIAS/intellij-antlers/releases/latest)
before reporting an issue.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately through GitHub Security Advisories by opening a
private report via the
[Security tab](https://github.com/BALOTIAS/intellij-antlers/security/advisories/new).

Please include as much of the following as you can:

- The plugin version and your IDE (e.g. PhpStorm) version.
- A description of the vulnerability and its potential impact.
- Steps to reproduce, a proof of concept, or a code sample if available.

### What to expect

- **Acknowledgement** within 5 business days of your report.
- **An initial assessment** (accepted / declined, with reasoning) within 14
  days, along with an indication of the next steps.
- For **accepted** reports, we will work on a fix, keep you updated on progress,
  and credit you in the release notes unless you prefer to remain anonymous.
- For **declined** reports, we will explain why the issue is out of scope.

Please give us a reasonable amount of time to address the issue before any
public disclosure.
